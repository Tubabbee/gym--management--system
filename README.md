# Gym Management System

This is a simple Gym Management System website made using Flask, HTML, and CSS.

## Pages
- Home Page
- About Us Page
- Membership Page

## Technologies
- Flask
- HTML
- CSS

## How to Run
1. Install Flask: `pip install flask`
2. Run app.py: `python app.py`
3. Open browser: [http://127.0.0.1:5000/]
